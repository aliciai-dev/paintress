# 2026-11-15T15:39+08:00 — Ship .d.ts: pin schema output types instead of disabling dts

`tsdown.config.ts` 里 `dts: false` 挂了两年的债（`specs/PLAN.md` 未决问题、`FUTURE.md` 发布工具链）。裸推断下 zod passthrough 的输出类型会被整段序列化进 `.d.ts`：

- `NodeSchema` 先撞 TS 序列化上限（TS7056，`src/schema/nodes.ts:225`）+ 文档 schema 三处；
- 2026-11-11 实验只给 `NodeSchema` 硬加注解能过构建，但 `index.d.ts` 1548 KB（包体 164 KB → 1.67 MB）。

## 做法

1. `src/schema/typed.ts`（新增）：`TypedSchema<T>` / `TypedObject<T>`（后者保留 `.shape` 供规格一致性测试枚举字段名）与编译期断言 `AssertSame<Actual, Declared>`。
2. `src/schema/nodes.ts`：手写公共形状 `NodeBaseFields` / `LayoutFields` / `GraphicsFields` + 13 个 `*Node` 接口 + `UnknownNode`，`PenNode` 是它们的 union；每个 schema 的运行时对象仍原样构造，只在导出处标注输出类型；末尾用 `AssertSame<z.infer<typeof 未导出的同一 const>, 手写类型>` 把关（断言常量不导出，不进 `.d.ts`）。
3. `src/schema/document.ts`：同样处理 `PenDocument` / `PtrDocument` / `VariableDef` / `XPaintress` / `ThemedValue`。
4. `src/schema/styles.ts`：`StrokeBlock` / `GraphicsBlock` 按 `typeof Fills`、`typeof Effects` 等引用标注 —— 这两块原先在声明里把同一个 fill/effect union 内联了 4~5 份（约 100 KB）。
5. `enums.ts` / `scalars.ts` / `styles.ts` 补上与 const 同名的类型别名（沿用 `scalars.ts` 已有写法）。
6. `tsdown.config.ts`：`dts: true` + `hash: false`（产物名固定成 `dist/index.d.ts`）。
7. `package.json`：顶层 `types`，`exports["."]` / `exports["./mcp"]` 各加 `types`。
8. `scripts/verify-package.mjs`：exports 的每个条件（含 `types`）、`main`、`types` 都检查落地；新增「`dist/**/*.d.ts` 相对引用可解析」与「`index.d.ts` ≤ 512 KB」两道闸。

## 证据

- `pnpm check`：0 错误。
- `pnpm test`：34 文件 / 440 用例全绿。
- `pnpm build`（tsdown + ui）与 `pnpm verify:pkg` 通过；`npm pack --dry-run`：250.5 kB tarball / 24 files，`index.d.ts` 110 KB（gzip 13 KB）。
- 独立 TS 消费方工程（NodeNext + strict，`/tmp/ptypes`）编译通过：`PenDocument`、`PtrDocument`、`PenNode` 收窄、`FrameSchema.shape`、`DocumentSchema.parse` 均可用。
- 行为等价性：所有 schema 的运行时构造未变（只有常量重命名 + 类型标注），规格一致性测试（`test/spec-conformance.spec.ts`）仍绿。

## 注意

- 新增/改动**导出**的 zod schema 必须带输出类型标注，否则 `pnpm build` 报 TS7056；`pnpm check` 是 `noEmit`，抓不到这一条。决策记录：`.agents/memory/ARCHITECTURE.md#D-013`。
- `UnknownNode.type: string` 使 `node.type === 'text'` 的收窄仍保留 UnknownNode 分支 —— 与旧推断行为一致，不是本次引入的回归。
