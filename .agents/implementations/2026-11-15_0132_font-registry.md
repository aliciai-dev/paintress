写 `"Inter"`，而应用实际用 `Inter Variable + Noto Sans SC Variable`。WSL 下查看器（Windows 浏览器）

## 改了什么

- `__preset.ptr` 新增 `x-paintress.fonts`：`default`（font token key 或 family）与 `families`（family → `source.kind` =
  web/css/file/system/bundle + `preview` + 可选 `metrics`）。`paintress_font` 提供 list / add / remove / default；
  `system`/`bundle` 强制 preview，css/file 路径必须在项目内且存在，web 必须是 http(s)。
- 渲染计划（`planFonts`）：web/css 进 `<link>`、file 进 `@font-face`、带 metrics 的 preview 用别名 family；
  URL 由调用方给（查看器 `/files`，截图 `file://`，导出 data URI）。栈顺序是「真字体 → 替代 → sans-serif」，
  节点没写 fontFamily 时用 `fonts.default`，未配置则用内置 Inter + Noto Sans SC（jsDelivr fontsource，版本钉死）。
- 字体 CSS **异步注入**（脚本建 `<link>`，`window.__paintressFontsReady` 作为等待点）：
  外链样式表不再阻塞 load；截图与探针等它 + `document.fonts.ready`（3s 超时），不再用固定 120ms。
- 截图结果新增 `fonts: { status, checked, missing, substituted }`，缺失写进 warnings；
  Chromium 加持久磁盘缓存（`PAINTRESS_HOME/chromium-cache`），分片只下一次。
- 查看器注入宽度法探针（`document.fonts.check` 不可靠），侧栏版本号旁出字体徽章：加载数 / 缺失数与替代字体提示。
- `/files` 对字体给一年 immutable 缓存 + 32 MB 读取上限（运行时保护，不是项目政策）。
- `validate` / `audit` / `doc_info` / `get` / 写路径都报告字体缺口：缺 fontFamily、未登记 family、system 无 preview。
- `PAINTRESS_NO_WEB_FONTS=1` 关闭内置网络字体（CI / 离线）；测试统一设置，避免测试依赖外网。
