# 2026-11-14T20:50+08:00 — 查看器三件：属性面板 / 快速切换 / 单帧导出（A 批）

operator 点单的三件查看器功能，加上截图倍率的新规则。规格：`specs/viewer-inspector.md`、
`specs/viewer-file-switcher.md`、`specs/frame-export.md`。

## 改动

### A0 截图倍率（先落，A3 依赖它）

- `planShotScale(requested, w, h)`：先夹进 **0.2–2**，再按设计尺寸等比压进 **8192px** 单边上限。
  `1x` 就是查看器里的 `1:1`（画板设计像素），两端尺寸可互相推算。
- `paintress_screenshot` / `paintress shot`：`scale` 从「1–4 整数、默认 2」改成「0.2–2 连续、**默认 0.8**」；
  返回值带上实际倍率，夹/压都有 warning 说明。
- `screenshotPen` 先按声明尺寸估一版倍率量裁，只有真的被上限压过时才换一页重截
  （`deviceScaleFactor` 是 context 级的，改不了）。

### A1 只读属性面板

- 新接口 `GET /api/node?project&path&id`：返回**磁盘上的原始节点** + 变量表（项目预设打底、本地优先），
  用于把 `$color-brand` 显示成「引用 → #205080」。404/400 分得清（项目未注册 / 节点不存在 / 路径穿越）。
- `ui/src/inspector-panel.tsx`：复用 `Panel` 壳，分 标识 / 几何 / 布局 / 外观 / 文本 / 其它；
  颜色出色块、`$var` 出解析值、对象折成 JSON；`ref` 显式给出后代覆写条数。**没有任何输入控件**——
  写路径仍然只有 MCP / CLI。
- 选中即取数（`/api/node` 一次请求），换选中丢弃过期响应；SSE `change` 且面板开着时重取。
  手动关掉后本次会话不再自动弹。同时把「点空白」补成取消选中（原来什么都不做）。

### A2 多稿快速切换

- `ui/src/quick-switch.tsx` 复用 `Modal` 壳：输入即过滤、↑↓ 选、Enter 开、Esc 关；
  `Ctrl/Cmd+K` 与工具条「切换设计稿」两个入口；输入法组合中的 Enter 不误触发。
- **顺手修掉一个隐患**：iframe 换稿原来是改 `src` 属性，每换一次稿就给标签加一条浏览历史，
  而「单历史标签」正是自动关窗的前提（D-009）。现在首次装载用 `src`，之后一律 `location.replace`；
  用例直接断言切换前后 `history.length` 不变。

### A3 单帧导出

- `GET /api/export?project&path&board&scale(0.5|1|2)`：走同一条 `screenshotPen`，临时文件流式回传后删除；
  `Content-Disposition` 同时给 ASCII 兜底与 RFC 5987 中文名，`X-Paintress-Scale` 报告实际倍率。
- 画板条右侧出现「倍率 + 导出 PNG」，只在选中具体画板时显示（「全部」不导出）；倍率按浏览器记住。
- 无 Chromium → 501 并说明；画板名歧义 → 400 并列出候选。
