# 查看器多稿快速切换

## 需求

一个项目里设计稿一多（design/ 下十几份），侧栏平铺列表就要滚着找、还得读文件名。
要一个**键盘可达**的快速切换：像编辑器的「快速打开」，而不是再做一个下拉框。

## 方案

- **入口**：① 工具条路径旁「设计稿」按钮；② `Ctrl/Cmd+K`（输入框/文本域内不拦截，沿用现有 `isTyping` 判定）。
  侧栏的文件列表保留，两者是同一份数据（`files()`）。
- **形态**：新组件 `ui/src/quick-switch.tsx`，壳用现有 `Modal`（`confirm.tsx`）保证遮罩/Esc/焦点一致；
  内部：搜索框（自动聚焦）+ 结果列表（文件名包含匹配，忽略大小写；无匹配时显示空态）。
- **键盘**：↑↓ 移动、Enter 打开、Esc 关闭；鼠标点击等价。当前文件高亮并默认选中。
- **打开**：调用现有 `openFile(f)`；URL 用 `replaceState`（**不新增浏览历史**——单历史标签才允许页面自动关窗，见 `viewer-autoclose.md`）。
- **显示**：文件名 + 所在目录（截断中间）；当前项目深度提示沿用侧栏的 `depth`。

## 验收

1. 20+ 份设计稿时，输入 2 个字符即可命中；↑↓/Enter/Esc 全流程可用。
2. 打开后 URL 同步、`history.length` 不增加；关窗倒计时不受影响（自动化用例断言 length 不变）。
3. 无文件 / 无项目时不出现入口；输入法组合状态下不误触发 Enter。
4. 侧栏列表与快速切换选中的是同一个文件，状态一致。
